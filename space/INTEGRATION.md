# CarPrint API for the team site (antigradient.uz)

The Space `Azamaka/carprint-demo` is both the jury demo and the processing server. The site calls it with
`@gradio/client`, the same way the traffic demo was wired in `LiveDemoSection.jsx`.

- Demo page (the "Test" button can simply open it): https://huggingface.co/spaces/Azamaka/carprint-demo
- Direct app URL (no HF frame): https://azamaka-carprint-demo.hf.space
- API description, generated by Gradio: the "Use via API" link at the bottom of the demo page.

## Endpoints

| Endpoint | Inputs | Outputs (in order) |
|---|---|---|
| `/damage` | `photos`: 1–8 images, `model`: `"cobalt"` (prices and sizes) | gallery of overlays, findings table, repair range (markdown), JSON |
| `/video` | `clip`: video up to 90 s, `model` | gallery of 6 key frames, findings table, repair range, JSON |
| `/compare` | `reference`: 1–8 photos of the last visit, `current`: 1–8 photos today, `model` | verdict (markdown), match image, "what changed" table, repair range of new damage, JSON |

The last output of every endpoint is the full JSON (decision, findings with class, part, size, score, status,
`cost_estimate` with `p10/p50/p90`, `device`, `latency_ms`). Images come back as URLs served by the Space.

## React (Vite)

```bash
npm i @gradio/client
```

```jsx
import { Client, handle_file } from "@gradio/client";

const SPACE = "Azamaka/carprint-demo";

export async function checkDamage(files, model = "cobalt") {
  const client = await Client.connect(SPACE);
  const res = await client.predict("/damage", { photos: files.map((f) => handle_file(f)), model });
  const [gallery, table, costMarkdown, json] = res.data;
  return { overlays: gallery.map((g) => g.image.url), table, costMarkdown, json };
}

export async function sameCar(referenceFiles, currentFiles, model = "cobalt") {
  const client = await Client.connect(SPACE);
  const res = await client.predict("/compare", {
    reference: referenceFiles.map((f) => handle_file(f)),
    current: currentFiles.map((f) => handle_file(f)),
    model,
  });
  const [verdictMarkdown, matchImage, changes, costMarkdown, json] = res.data;
  return { decision: json.decision, verdictMarkdown, matchImage: matchImage?.url, changes, costMarkdown, json };
}
```

For progress and queue position use `client.submit(...)` and listen to `"status"` events instead of `predict`.
Do not put an HF token in `VITE_*` variables: they end up in the public bundle; the Space is public and needs none.
