Как это работает

Один кадр проходит общий контроль и две ветки: личность машины и повреждения

Гейт качества кадра резкость, экспозиция, блики не больше 25 %, машина занимает не меньше 8 % кадра. Пороги откалиброваны на 224 фото: отсекаются худшие 3–5 %.

Повреждения · качество

Длинное обучение подняло точность на 40 %; рабочий порог выбран по данным

Проверка на отложенных 15 % датасета HITL: 122 фото, 1 225 объектов, разбиение seed 42. Модель эти фото не видела. mAP — средняя точность по классам по правилам COCO; mask mAP считает совпадение контуров, а не рамок.

Та же машина · качество

Ноль ложных совпадений на 400 сравнениях разных машин

Протокол в духе ISO/IEC 19795: «своя» пара — та же машина в разные сессии, «чужая» — разные машины той же или другой модели. Тестовый набор заморожен по хешу до первого прогона, пороги на нём не подбирались. Для нуля ошибок указана верхняя граница 95 % по Клопперу — Пирсону.

Пределы

Где система ошибается и что она делает в этом случае

  • Повреждения: mAP@0,5 = 0,25это подсказка мастеру, а не судья. Всё ниже 0,6 помечено «проверить мастеру»; смета считается для подтверждённых находок.
  • Ложная тревога на чистых машинах29 % чистых фото получают хотя бы одну находку при пороге 0,45 (часть может быть реальными мелкими дефектами).
  • Перекос в данных HITLснятые номера аукционных машин размечены как «нет детали», и модель это выучила. На машинах с номерами не проявляется; модель деталей уберёт это по классу «номер».
  • Модель деталей ещё обучаетсяпока деталь «не определена», размер считается по высоте кузова, смета шире.
  • Разные ракурсыпри случайных ракурсах автоматическое «та же» редкое — система говорит REVIEW вместо угадывания. В продукте приёмка и выдача снимаются по одному плану из 8 ракурсов.
