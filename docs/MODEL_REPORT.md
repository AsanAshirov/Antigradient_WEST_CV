# Паспорт моделей CarPrint

Что распознаёт система, на каких данных обучена, как мы её проверяли, с какой скоростью работает и сколько это
стоит. Цифры — из наших прогонов 10–11 октября 2026 года. Оформленная версия с графиками:
[docs/model_report.html](model_report.html). Методика проверки — [EVALUATION.md](EVALUATION.md).

**Демо и API:** https://huggingface.co/spaces/Azamaka/carprint-demo · подключение к сайту — [space/INTEGRATION.md](../space/INTEGRATION.md)

| Ключевая цифра | Что это |
|---|---|
| **0 / 400** | ложных «та же машина» на разных машинах (верхняя граница 95 % — 1,5 %) |
| **0,248** | mAP@0,5 сегментации повреждений (после 12 эпох было 0,177, +40 %) |
| **1,5 с** | фото → повреждения → смета на GPU; 12–16 с на бесплатном CPU |
| **$0,0003** | GPU-время одного осмотра из 8 кадров на T4 ($0,40 в час) |

## Как это работает

1. **Гейт качества кадра** — резкость, экспозиция, блики ≤ 25 %, машина ≥ 8 % кадра; пороги откалиброваны на 224 фото.
2. **Силуэт машины** — RF-DETR-Seg Nano (COCO): дальше считается только кузов.
3. **Ветка A, «та же машина?»** — ALIKED (до 2 048 точек) → LightGlue → MAGSAC++ (панель = плоскость) →
   тест a-contrario, NFA < 10⁻³ → веса когорты K = 8 (вычитаем дизайн модели) → ≥ 6 совпавших ячеек → ТА ЖЕ / REVIEW / ДРУГАЯ.
4. **Ветка B, «что повреждено и сколько стоит»** — RF-DETR-Seg Medium (маски 7 классов) → масштаб по колесу
   (D = 25,4·d + 2·W·AR/100 мм), номеру 520 × 110 мм и высоте кузова → размер в см с поправкой 1/cos ψ →
   операция (полировка … замена) → 4 000 сценариев Монте-Карло по ценам Ташкента → P10 / P50 / P90.
5. **Паспорт визита** — SHA-256 кадров, pHash против повторных фото (≤ 10 бит из 63), подпись Ed25519, цепочка записей.

## Стоимость

- Осмотр из 8 кадров: ≈ 3 с GPU → **≈ $0,0003** на T4; 1 000 осмотров ≈ $0,33.
- Обучение модели повреждений: 68 мин на Kaggle T4 — бесплатно (по тарифу T4 ≈ $0,45).
- Хостинг демо: бесплатный CPU на HF; ZeroGPU в HF PRO — $9 в месяц; выделенный T4 — $0,40 в час.

## Пределы

- Повреждения, mAP@0,5 = 0,25 — подсказка мастеру; всё ниже 0,6 помечено «проверить мастеру», смета — для подтверждённых находок.
- 29 % чистых фото получают ложную находку при пороге 0,45.
- В HITL снятые номера аукционных машин размечены как «нет детали» — модель это выучила; на машинах с номерами не проявляется.
- Модель деталей обучается: пока деталь «не определена», размер считается по высоте кузова.
- При случайных ракурсах автоматическое «та же» редкое — система говорит REVIEW; в продукте план из 8 ракурсов.
